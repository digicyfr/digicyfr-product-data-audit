# Security policy

## Supported release

Security fixes are considered for the latest published release of digicyfr-product-data-audit. The current candidate is 0.1.0.

## Private reports

Please use **Report a vulnerability** on this repository's GitHub Security tab. Maintainers should enable GitHub private vulnerability reporting before the first public release. If that option is unavailable, contact Digicyfr through https://digicyfr.com/ to arrange a private channel. Do not post exploit details, private scan data, or credentials in a public issue.

Include the plugin version, WordPress/PHP versions, steps to reproduce, expected and observed behavior, and the minimum example needed to investigate. We will acknowledge and triage reports through the private channel, coordinate a fix, and publish an advisory when appropriate. No response-time or bounty commitment is implied.

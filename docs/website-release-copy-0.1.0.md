# Website release copy — 0.1.0

## English

**Digicyfr Product Data Audit** is a free, open-source WooCommerce plugin for merchant-selected checks of empty product fields. Select only the rules that fit your catalog, scan in bounded manual batches, then review precise findings with product edit links and a guarded CSV. It never changes products, reads orders or customers, calls a remote service, or gives a store score. A completed scan is a best-effort snapshot, not proof that the catalog stayed unchanged.

Tested on WordPress 7.1, PHP 8.3.33, MariaDB 11.4.13, and WooCommerce 8.9.0 and 11.2.2, each with HPOS on and off. The exact ZIP checksum is in the local QA record. GPL-2.0-or-later. Updates are manual ZIP uploads. Public source and download links are pending publication.

## Polski

**Digicyfr Product Data Audit** to darmowa wtyczka WooCommerce o otwartym kodzie, która sprawdza puste pola produktów według reguł wybranych przez sprzedawcę. Wybierz reguły odpowiednie dla katalogu, uruchom ręczny skan w ograniczonych partiach, a potem przejrzyj dokładne wyniki z odnośnikami do edycji i zabezpieczonym plikiem CSV. Wtyczka nie zmienia produktów, nie odczytuje zamówień ani danych klientów, nie łączy się z usługą zewnętrzną i nie wystawia oceny sklepu. Ukończony skan jest przybliżonym obrazem katalogu w chwili skanowania, nie dowodem niezmienności danych.

Przetestowano z WordPress 7.1, PHP 8.3.33, MariaDB 11.4.13 oraz WooCommerce 8.9.0 i 11.2.2, z włączonym i wyłączonym HPOS. Dokładną sumę kontrolną pliku ZIP zawiera lokalny protokół QA. Licencja GPL-2.0-or-later. Aktualizacja odbywa się przez ręczne wgranie pliku ZIP. Publiczne odnośniki do kodu i pobrania zostaną dodane po publikacji.
